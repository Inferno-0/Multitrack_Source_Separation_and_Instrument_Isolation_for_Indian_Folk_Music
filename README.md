# Project Title
Indian Folk Music Processing and Generation Framework

Subtitle:
An Indian Knowledge Systems (IKS) Internship Research Project

# Project Overview
The objective of this repository is to build a modular research framework for Indian folk music. The framework is designed to support:
* dataset curation
* audio preprocessing
* vocal separation
* individual instrument separation
* feature extraction
* voice conversion
* instrument replacement
* instrument addition
* future music generation

The repository follows a research-first philosophy emphasizing reproducibility, modularity, and documentation.

# Research Objectives
* Curate standardized datasets.
* Build rich metadata.
* Standardize audio.
* Separate vocals.
* Separate individual instruments.
* Extract musical features.
* Build reusable musical components.
* Prepare for future generative music research.
