# Experiment ID

# Title
Baseline Source Separation using Pretrained HT-Demucs on Indian Folk Music

# Objective
The objective was to evaluate the performance of the pretrained HT-Demucs model on an Indian folk music recording without fine-tuning, with particular attention to vocal separation quality and preservation of traditional folk instruments.

# Hypothesis
HT-Demucs was expected to separate vocals successfully but was not expected to isolate individual traditional folk instruments because it was trained using broad source categories.

# Dataset
One representative Bihu recording from the curated dataset.

# Model
HT-Demucs (Pretrained)

# Experiment Summary
This experiment involved applying the pretrained HT-Demucs model to a single Bihu folk music recording to perform a baseline, two-stem (vocal and accompaniment) source separation. The generated stems were qualitatively analyzed to assess vocal clarity, instrument preservation, and overall audio quality. Note that execution logs are generated automatically by the experiment notebook and stored inside the logs directory.
